# Exploding Kittens Game Rules

### Official Reference

This project follows the **Exploding Kittens: Original Edition** rules for 2–5 players.

- [Official rules page](https://www.explodingkittens.com/pages/rules-kittens)
- [Official English rulebook — 2022 edition](https://dumekj556jp75.cloudfront.net/exploding-kittens/English.pdf)

The linked rulebook defines the complete gameplay, card effects, and special combinations. The sections below specify the deck composition and setup requirements.

### Game Setup

1. Remove all Exploding Kittens and Defuse cards.
2. Give each player one Defuse.
3. Return the extra Defuse cards:
    - **2–3 players:** return two; exclude the others.
    - **4–5 players:** return all remaining Defuses.
4. Shuffle and deal seven additional cards to each player.
5. Add one fewer Exploding Kitten than the number of players. Exclude unused Exploding Kittens.
6. Shuffle again to prepare the draw pile.
7. Choose the first player. Play proceeds clockwise.

Each player starts with eight cards, including **at least one Defuse** and **no Exploding Kittens**. Additional Defuses may appear among the seven dealt cards.
